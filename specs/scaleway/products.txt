#
#   <slug-portail> [<nom-produit>] <version>

# Le slug est celui de l'URL du portail developers, et il ne coïncide pas
# toujours avec le nom du produit dans les SDK. Mesuré sur le portail :
# baremetal s'y appelle elastic-metal, k8s s'y appelle kubernetes, lb s'y
# appelle load-balancer/zoned. Un produit ajouté ici se vérifie sur sa page,
# il ne se devine pas depuis le SDK.
#
# Instance a servi de premier produit : la chaîne complète a fonctionné sur lui
# avant qu'un second n'arrive. `lb` est ce second, et il est choisi pour une
# raison mesurable plutôt que par appétence : la stack d'exemple déploie déjà un
# load balancer, donc ses modules sont exercés contre le cloud réel dès le
# premier jour, sans écrire de nouvelle plateforme. C'est le produit dont la
# preuve coûte le moins cher.
